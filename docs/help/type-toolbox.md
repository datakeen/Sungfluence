# Type toolbox

Open it from **Text art → Type toolbox** (the whole window, or straight at one of its tabs), with **Shift Ctrl T**, or with the **Type toolbox** button above any text box in the panels. When you open it from a text box, the buttons at the bottom put the result straight back into that box.

There are six sections, and they all work on the text you type in the box at the top.

## Styled text

These are not fonts. Each style swaps your letters for different characters that already exist in Unicode, so the look travels with the text into a chat, a profile or a document that allows no formatting.

Pick a family on the left, then a style on the right. Every style shows your own text, so you see the result before you take it. The star keeps a style under **Favorites**.

| Family | What is in it |
| --- | --- |
| Weight and slant | Bold, italic, bold italic, sans, sans bold, sans italic, sans bold italic, typewriter. |
| Handwriting and old print | Script, script bold, fraktur, fraktur bold, double struck. |
| Size and position | Small capitals, raised, lowered, wide. |
| In boxes and circles | Circles, dark circles, squares, dark squares, brackets, flag letters. |
| Turned around | Upside down and mirrored. |
| Look-alike letters | Greek, Cyrillic, Cherokee, rune, curly and Thai look-alikes, all marked decorative. |

### Mixing styles

- **One style** uses the style you picked.
- **Alternating** lets the styles you tick take turns, letter by letter.
- **Mixed** picks from the ticked styles at random.
- **Ransom note** does the same and also changes the capitals, like a note cut out of a newspaper.

### Lines and marks

**Lines** puts a line through, under or over every letter. **Marks on the letters** piles marks above, through or below them; the slider sets how many, and SungFluence keeps a limit so chat apps can still show it.

### Before you paste it

Under the result sits a line you can open, **Before you paste it**. It opens by itself when something is wrong. It is honest about what the text will do out in the world:

- **The three counts.** Letters as people see them, characters, and units. A box with a limit, such as a profile, counts the units, so styled text fills more of it than it looks.
- **Blank boxes.** SungFluence draws every character and checks whether your computer has a picture for it. If not, it says so, because readers would see empty boxes.
- **Screen readers.** Fancy letters are read out one by one as "mathematical bold" and so on. A plain copy is always offered: copy it, or put it back in the box above.
- **Decorative styles** are marked. The look-alike letters are real letters of another writing system, so they are not really your words.

Urdu, Arabic and other scripts are left as they are, because these styles only cover Latin letters and digits.

## Symbols

Sets of arrows, stars, hearts, music, maths, box drawing, blocks, shapes, Braille, games, office signs, brackets, dots, currency, Arabic ornaments, zodiac and flourishes.

Search finds a symbol in several ways:

| You type | It finds |
| --- | --- |
| `heart` | by name |
| `arrow*` | a star stands for anything, so this finds every arrow |
| `U+2665` | by code point, also written `0x2665` |
| `&hearts;` | by HTML entity |
| `9829` | by Windows Alt code or plain number |

Click a symbol to add it to **Picked**. Under the grid, SungFluence shows how to type that symbol elsewhere.

### Draw a symbol

**Draw a symbol**, above the list of sets, opens a pad. Sketch a shape with the mouse or a finger and SungFluence shows the symbols that look most like it: a circle finds ○ ◯ ⚪ ◌, a triangle finds △ ▲ ∆. Where you draw it and how large make no difference, because each shape is fitted to the same box before it is compared. **Clear** starts again, and **Back to the sets** leaves the pad.

## Faces

Ready-made faces in categories, and a **Build one** page where you choose each part: arms, cheeks, eyes and mouth. **Surprise me** picks the parts at random.

## Decorations

Decorations go on one side of your text or on both. On the second side everything is mirrored, so brackets and arrows turn around correctly and the result still reads properly in Urdu and Arabic.

**Dividers** makes a separator line of any width, from 4 to 80 characters, with an optional ornament at each end.

## Sharing

Pick where the text is going, from Instagram, X, Bluesky, TikTok, LinkedIn, YouTube and WhatsApp. The panel then shows:

- **A preview** of how it will look there: a bio, a post with the "… more" cut where the app folds it, or a single-line name.
- **The count**, in the way that place counts. X is counted by its own published rule, where most Latin letters count as one and most other characters as two. The letters you see and the units a box counts are shown next to it, because fancy letters take more room than they look.
- **How much would be cut off**, if it is over the limit.

Three buttons fix the usual problems:

- **Make the line breaks stick.** Instagram and some others drop a line break when the line before it is empty, or when a line ends in a space. This takes the trailing spaces off and puts an invisible character in the empty lines, so the shape of the text survives the paste.
- **Cut it to fit** shortens the text to the limit, at a space, so no word is left half written.
- **Take the styling off** turns fancy letters back into plain ones.

The limits were taken from public guides in November 2026, not from the apps themselves, and apps change them. Treat them as a guide.

## Expansions

Type `(shrug)` or `:shrug:` in **any** text box in SungFluence and it turns into the text you set here. The list starts with some common ones and you can add your own. It is saved on this computer.

The same list can be sent to the tools that do this everywhere on your computer:

- **Espanso**, a file for Windows, Mac and Linux.
- **AutoHotkey**, a script for Windows.
- **Mac and iPhone**, a file for Settings → Keyboard → Text Replacements.
- **Plain list**, a simple text file.

## Where the result goes

The buttons at the bottom of the window:

- **Copy** puts it on the clipboard.
- **Place on canvas** makes it a text object on the Vector layer, which you can move, scale and turn.
- **Place each separately**, when you have picked more than one symbol, makes one object for each of them, laid out in a row. Each is then a sticker you can move, scale, turn and color on its own.
- **Add to the text** and **Use for …** appear when you opened the toolbox from a text box, and put the result into that box.

Because text art styles read the text in those boxes, a styled or decorated line also becomes the letters of a portrait, a spiral or a calligram.
