# Plugins

A plugin is a small file that adds an effect. Its effects appear in the Text art panel under **Style**, in **Extra effects**, next to Confetti and Contours, which come with SungFluence.

## Add a plugin

1. Click **Plugins** at the top of the window, or choose **Effects → Plugins…** in the menu bar.
2. Click **Load plugin…** and pick the `.js` file.
3. The new effect appears under Extra effects. SungFluence remembers it for next time.

The **Add effect** tile under Extra effects does the same.

Plugins run code inside SungFluence. Only load plugins from people you trust.

## Remove a plugin

Open **Plugins** and click **Remove** next to it. Effects that come with SungFluence cannot be removed.

## Make your own

Click **Get the template** in the Plugins window. It is a short, commented file: change the name and the drawing part, then load it. The full guide for plugin authors is [docs/PLUGINS.md](https://github.com/datakeen/Sungfluence/blob/main/docs/PLUGINS.md) on GitHub.
