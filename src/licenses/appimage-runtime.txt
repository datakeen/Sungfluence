The AppImage runtime inside the Linux AppImage file

The Linux AppImage file starts with a small program, the AppImage runtime. It mounts the app that is
packed inside the file and starts it. electron-builder adds it from its AppImage bundle
(appimage-12.0.1). SungFluence ships it unchanged. The .deb and .tar.gz files for Linux do not carry it.
